> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the pre-group vertical slice — login/register, group create/join, group lobby with players list and "Start draft" — and connect the WebSocket once the user is in a group, wiring real `hasGroup` into the phase router.

**Architecture:** Two feature modules (`features/auth`, `features/lobby`) each with `data/` (repository over the foundation `dioProvider`), `application/` (Riverpod notifiers), `presentation/` (GoRouter screens), `model/` (freezed DTOs). A shared snackbar/error helper lands in `shared/widgets`. WS connection is established post-group via a platform-conditional channel factory (header on IO, `?token=` query on Web).

**Tech Stack:** Flutter, Riverpod, GoRouter, Dio, freezed/json_serializable, web_socket_channel, flutter_test + http_mock_adapter + mocktail. Foundation (Plan 1) provides `dioProvider`, `tokenStoreProvider`, `isAuthenticatedProvider`, `TokenPair`, `SeasonState`, `WsService`, `AppTheme`, `routerProvider`, `AppException`/`mapDioError`.

```dart
class AsyncValueView<T> extends StatelessWidget {
  const AsyncValueView({super.key, required this.value, required this.data, this.onRetry});

  final AsyncValue<T> value;
  final Widget Function(T value) data;
  final VoidCallback? onRetry;

  @override
  Widget build(BuildContext context) {
    return value.when(
      loading: () => const Center(child: CircularProgressIndicator()),
      error: (e, _) => Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(errorMessage(e), textAlign: TextAlign.center),
            if (onRetry != null)
              Padding(
                padding: const EdgeInsets.only(top: 12),
                child: FilledButton(onPressed: onRetry, child: const Text('Retry')),
              ),
          ],
        ),
      ),
      data: data,
    );
  }
}
```

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../../../core/api/auth_state.dart';
import '../data/auth_repository.dart';
import '../model/auth_requests.dart';

class AuthController extends AutoDisposeAsyncNotifier<void> {
  @override
  Future<void> build() async {}

  Future<void> login(String login, String password) async {
    state = const AsyncLoading();
    state = await AsyncValue.guard(() async {
      final pair = await ref
          .read(authRepositoryProvider)
          .login(LoginRequest(login: login, password: password));
      await ref.read(tokenStoreProvider).save(
            access: pair.accessToken,
            refresh: pair.refreshToken,
          );
      ref.read(isAuthenticatedProvider.notifier).state = true;
    });
  }

  Future<void> register(String email, String username, String password) async {
    state = const AsyncLoading();
    state = await AsyncValue.guard(() async {
      final pair = await ref
          .read(authRepositoryProvider)
          .register(RegisterRequest(email: email, username: username, password: password));
      await ref.read(tokenStoreProvider).save(
            access: pair.accessToken,
            refresh: pair.refreshToken,
          );
      ref.read(isAuthenticatedProvider.notifier).state = true;
    });
  }

  Future<void> logout() async {
    try {
      await ref.read(authRepositoryProvider).logout();
    } catch (_) {
      // best-effort; clear locally regardless
    }
    await ref.read(tokenStoreProvider).clear();
    ref.read(isAuthenticatedProvider.notifier).state = false;
  }
}

final authControllerProvider =
    AutoDisposeAsyncNotifierProvider<AuthController, void>(AuthController.new);
```
